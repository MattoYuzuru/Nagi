# Nagi

Nagi — self-hosted система исследования и управления портфелем для одного
частного инвестора без статуса квалифицированного, работающего на российском
рынке. Цель — дисциплинированное инвестирование с низким оборотом на горизонте
лет. Это не HFT, не внутридневная торговля и не передача счёта под управление ИИ.

Текущий статус: **исследование и предложение по архитектуре**. Продакшн-кода для
торговли пока нет. Старый ноутбук и CSV сохраняются только как свидетельство
исходного замысла.

Следствие из размера портфеля и издержек: целевой бюджет оборота — около 100% в
год, что соответствует примерно **двум сделкам в месяц**, причём большинство из
них — покупки на ежемесячное пополнение. Продажа является исключением, а не
рутиной. Обоснование — в разделе 11 документа с проектными решениями.

## Принципы безопасности, которые не обсуждаются

1. Намерение совершить сделку формирует детерминированный версионированный
   алгоритм, а не языковая модель.
2. Результаты в песочнице и на теневых портфелях не дают права торговать
   реальными деньгами.
3. Реальное исполнение начинается в режиме только чтения; далее требуются явный
   гейт продвижения, токен с доступом только к одному счёту, жёсткие риск-лимиты
   и аварийный выключатель.
4. Каждое решение воспроизводимо из point-in-time данных и неизменяемой версии
   стратегии.
5. Результат измеряется после комиссий брокера, спреда, проскальзывания, налогов
   в рамках модели и с учётом денежных потоков — против инвестируемого бенчмарка
   полной доходности.

Репозиторий не является инвестиционной рекомендацией.
